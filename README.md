## 使用

直接打开 `index.html`，或通过 GitHub Pages 托管。无需安装依赖、无需构建。

- 单选、多选，提交后显示 Correct Answer 和原文 Comments。
- 自动恢复上次打开的题目，支持题号导航、章节筛选、搜索、错题与收藏。
- 保存已选答案、作答结果、收藏及个人笔记。
- 进度存于当前浏览器的 localStorage，**不会同步到 GitHub 或其他设备**。清理浏览器数据、换浏览器或更换网站域名会影响进度；请用“导出进度 / 导入进度”备份迁移。
- “查看答案”不算已作答；“重新作答”会清除该题旧的作答结果。
- 全书使用连续编号 1–167，同时保留 PDF 原有的 Topic 与每章题号。

## GitHub Pages

在仓库 Settings → Pages，选择 Deploy from a branch，选择当前分支与 `/ (root)` 后保存。

## 文件

- `index.html`, `style.css`, `app.js`: 页面及答题逻辑。
- `explanations.js`: 167 题英文解析、纠错与官方参考链接。
- `questions.js`, `assets/`: 从提供的 PDF 提取的题库与图片。

仅用于个人学习。题目、答案与评论沿用来源材料。
